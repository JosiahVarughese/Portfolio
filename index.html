Prior Coding Experience

I started learning how to program back in 2009 when I was about 14 years old, at the time one of my hobbies was 3D modeling & animation. I found that one of the 3D renderers I was using had a feature that allowed for visual programming using logic bricks. I quickly started learning to use this to build my own video games, I worked on many projects in this engine up until 2012 when I discovered Unity3D. A free realtime 3D engine intended for game development, unity however used actual code, C# specifically. I eventually worked up the nerve to teach myself how to write code and quickly fell in love with it. There were many weeks during my highschool days that I would wake up at 5:00am, go straight to the computer and code until 6:00pm, only stopping to eat. I worked on increasingly ambitions and complex projects, touching subjects like physics, advanced vector math, procedural generation, and even neural networks. Over the years I eventually started focusing on building simulations rather than games, these simulations were meant to answer questions, or to function as tools for other projects, really I was just fascinated with what code could do and was curious about what I could achieve with it. Admittedly more often than not this led to crashing my computer, but I was learning a lot and having a great time. In 2019 I started taking some online courses for web development, during this time I experimented with building moderation chat bots for the discord server I was in. I would often put in wacky features to amuse myself and my friends, at one point I actually turned the whole chat into a text based video game. It was shortly after this that I applied to an internship under York Solutions and began my career as a Software Engineer.
